One line of awkward small talk a robot says to another in an elevator: it calculated 4,096 conversation starters for the ride — and selected silence.

> I calculated 4,096 conversation starters for this elevator ride. I have selected silence.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
